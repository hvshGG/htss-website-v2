# HTSS & CO.

Адаптивный сайт компании на HTML, CSS и JavaScript. Шрифты, фотографии, иконки и видео локальные; сборка не зависит от CDN. Русская, казахская и английская версии переключаются на странице.

## Локальный запуск

Нужен Node.js 24 или новее:

```sh
npm ci
```

Скопируйте `.env.example` в `.env`. Адрес заявок уже указан: `info@htss-co.kz`. Для прямой отправки заполните SMTP-параметры; без них форма открывает черновик письма в почтовой программе посетителя.

```sh
npm run dev
```

Откройте `http://localhost:3000`. HTML и CSS обновляются после перезагрузки страницы. Контакты статической версии настраиваются в `site-config.js`; в режиме Node конфигурация берётся из `.env`.

## Подготовка к размещению

```sh
npm test
npm run build
npm start
```

Готовая статическая версия находится в `dist`. Подробные варианты размещения и настройки почты — в [DEPLOYMENT.md](DEPLOYMENT.md).

## Проверки

`npm test` проверяет серверный приём заявок, валидацию, защиту лимитера, обработку ошибок и доступ к файлам. Реальные письма в тестах не отправляются.

`npm run test:browser` после сборки запускает установленный Chrome/Chromium и проверяет мобильную/десктопную вёрстку на трёх языках, клавиатуру, меню, форму, ошибки доставки и работу без JavaScript. Если браузер не найден автоматически, задайте `CHROME_PATH`. Скриншоты сохраняются в `.cache/browser`.

Для SEO задайте окончательный HTTPS адрес `SITE_URL` перед сборкой. Не помещайте SMTP-пароли в публичные файлы или Git.
